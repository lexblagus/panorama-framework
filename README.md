# Global Megacity Panorama Monorepo

This repository is organized into three top-level projects:

- [`Framework`](./framework/README.md):  contains the canonical panorama specification, docs, and prompts.

   ***Start with this folder for the authoritative project context.***

- [`Images`](./images/PREVIEW.md):  contains generated outputs, composites, and reference imagery.

- [`Robot`](./robot/README.md):  contains the private Node/TypeScript CLI for image generation workflows.
