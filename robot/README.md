# Robot

`robot` is the private CLI package for the Global Megacity Panorama monorepo.

It is a Node.js + TypeScript ESM command-line tool that builds and executes recipe-based workflow plans.

## Requirements

- Node.js matching [`.nvmrc`](.nvmrc)
- npm

Optional:

- OpenAI API key for recipes/tasks that call `openai.generate-image`.

## Install

From the package directory:

```bash
nvm use
npm install
```

## Environment Variables

Copy [`.env.sample`](.env.sample) to `.env` and set values as needed.

Current variables:

- `OPENAI_API_KEY`: required only when executing `openai.generate-image` tasks.

## Usage

From the repo root:

```bash
./robot/bin/robot build --recipe examples/empty
./robot/bin/robot exec --recipe examples/empty
./robot/bin/robot run --plan examples/empty
./robot/bin/robot resume --plan examples/empty
```

From the package directory:

```bash
npm start -- build --recipe examples/empty
```

If `dist/index.js` is missing, [`bin/robot`](bin/robot) builds the package automatically before running it.

## Commands

### `build`

Builds a recipe into a plan file.

Arguments:

- `--recipe <recipe-id>`

### `exec`

Builds the recipe plan, then executes it from start.

Arguments:

- `--recipe <recipe-id>`

### `run`

Executes an existing plan from the beginning (resets task runtime state first).

Arguments:

- `--plan <plan-id>`

### `resume`

Executes an existing plan using persisted runtime state.
If no persisted runtime state exists, behavior is equivalent to `run`.

Arguments:

- `--plan <plan-id>`

### ID Format Rules

`recipe-id` and `plan-id` are the recipe/plan filename or folder name (without extension) and can include subfolders.

Examples:

- `examples/empty`
- `examples/panorama/v1`

Each segment must match:

- `^[a-z0-9_-][a-z0-9_.-]*$`

Invalid examples:

- `.bad`
- `../escape`
- `/absolute`
- `examples//empty`

## Project Structure

- [`bin/`](bin): CLI launcher wrapper.
- [`recipes/`](recipes): user-authored recipes (recommended location).
- [`src/`](src): runtime source code.
- [`src/services/`](src/services): task-capability services (`json`, `markdown`, `image`, `openai`, `workflow`).
- [`src/types/`](src/types): shared type contracts for builder, runner, plans, tasks, and recipes.
- [`tests/`](tests): fixtures and automated tests (`unit`, `integration`, `e2e`).
- [`plans/`](plans): generated execution plans (runtime artifact folder).
- [`transient/`](transient): persisted recipe runtime state (runtime artifact folder).
- [`dist/`](dist): compiled output.
